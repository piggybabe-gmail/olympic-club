# The Olympic Club by PT-Plam

แอปติดตามอาหาร การออกกำลังกาย และผลการเทรน สำหรับลูกค้าของ PT-Plam

- ลูกค้า: วันนี้ (อาหาร + แคลที่เหลือ) · ออกกำลังกาย · ร่างกาย · โค้ช
- เทรนเนอร์ (ผู้ดูแลฝ่ายงาน): ลูกค้า · ตารางงาน · บันทึกเทรน · สรุปวันนี้ · จัดการบัญชีลูกค้า
- เจ้าของระบบ: ภาพรวม · ลูกค้าทั้งหมด · เทรนเนอร์ · การตั้งค่าระบบ

สิทธิ์การเข้าถึงข้อมูลอยู่ใน `firestore.rules` · คู่มือการใช้งาน: `manual.html`
